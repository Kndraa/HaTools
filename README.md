# Kndra tools

Various tools useful for avatar creation in VRChat.

A lightweight, editor-only Unity package of small scripts that run quickly. Everything appears in Unity under **Tools > Kndra tools**. Nothing from this package is included in avatar uploads.

## Requirements

- Unity 2022.3 (the VRChat version)

## Installation

- **VRChat Creator Companion:** coming soon.
- **Manual:** copy this repository into your project's `Packages/com.kndra.tools` folder.

## Contributing

Each tool lives in its own file under `Editor/Tools/`, so changes to one tool never touch another. See [CLAUDE.md](CLAUDE.md) for the project philosophy, conventions and full tool documentation.
